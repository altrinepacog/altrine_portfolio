# ALtrine May Pacog — Portfolio

A from-scratch personal portfolio site built with plain HTML, CSS, and JavaScript.
Design theme: a records-management "card catalog" — index cards, folder tabs,
ledger lines, and a stamped request slip for the contact form, tying the visual
language back to Samantha's records management background.

## Files

- `index.html` — all page content
- `style.css` — all styling (design tokens at the top of the file)
- `script.js` — mobile nav toggle, contact form behavior
- `assets/` — put your photo and CV PDF here (see below)

## Before you publish, add your assets

1. Add a photo of yourself as `assets/profile.jpg` (a square-ish or portrait photo
   works best — the frame crops to a 4:5 ratio).
2. Add your CV as `assets/Pacog,AltrineMay_CV.pdf` so the "Download CV" button works.

If these files are missing, the page still works — the photo frame will show a
placeholder and the download button will just 404, so don't forget to add them
before sharing the link.
